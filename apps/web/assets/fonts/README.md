# Report card fonts

Noto Sans Regular and Bold (Google Noto project), used by the report-card
PDF (`src/lib/report-card-pdf.tsx`). Chosen because the PDF's built-in
fonts can't draw characters common in Nigerian names (Ọ, ẹ, ṣ …) or ₦.
